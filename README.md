# CrewAI Multi-Agent Project

A hands-on CrewAI multi-agent system demonstrating how multiple AI agents can collaborate through configured agents, tasks, tools, and workflows.

## Overview

The project is based on CrewAI and uses configurable agent and task definitions to build a collaborative multi-agent workflow. The current example produces a research report about large language models.

## Key Concepts

- Multi-agent AI systems
- Agent roles and goals
- Task configuration
- Agent collaboration
- Python-based AI workflows

## Technology

Python 3.10–3.12, CrewAI, UV, and OpenAI API.

## Run

Install dependencies with the project's CrewAI tooling and run `crewai run`.
